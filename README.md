# auditnet

Audit CSV/TSV net tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/auditnet/

## Install / run

```bash
git clone https://github.com/theworker02/auditnet.git
cd auditnet
node src/cli.js
node --test
```
